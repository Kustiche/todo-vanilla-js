# Todo

## Описание

Todo - приложение для управления списком задач.

## Технологии

- JavaScript
- CSS
- HTML

## Установка и запуск

1. Клонировать репозиторий

```bash
   git clone git@github.com:Kustiche/todo-vanilla-js.git
```

2. В терминале запустить команду

```bash
   npm install
```

3. Изменить название файла `.env.example` на `.env`
4. Для разработки использовать команду

```bash
   npm run dev
```

5. Для создания билд версии сайта использовать команду

```bash
   npm run build
```
